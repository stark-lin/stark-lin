蜩の<br>
鳴く夕暮ぞ<br>
憂かりける<br>
何時も盡きせぬ<br>
思為れども

藤原長能

*those evenings when*<br>
*the cicadas shrill are*<br>
*particularly*<br>
*sorrowful although my own*<br>
*sad thoughts are never-ending*
