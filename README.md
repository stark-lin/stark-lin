暮掛かる<br>
虛しき空の<br>
秋を見て<br>
思えず溜る<br>
袖露哉

攝政太政大臣　藤原良經

*as darkness begins*<br>
*to dim the empty skies of*<br>
*autumn I gaze out*<br>
*unaware of the drops of*<br>
*dew gathering on my sleeves*
